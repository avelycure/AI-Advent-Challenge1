# Конфиги агента

Один файл — один агент. Запуск чата с конфигом:

```bash
./run.sh --config configs/demo.yaml
```

Из кода:

```python
from llmagent import Agent, AgentConfig
agent = Agent(AgentConfig.from_file("configs/books-json.yaml"))
```

Ключ в конфиге не хранится: поле `api_key` оставлено пустым, и агент берёт
реквизит из переменной окружения провайдера или из файла рядом. Команда
`/config` в чате печатает действующий конфиг — ключ в выводе заменён на `***`.

| Файл | Чем отличается |
|---|---|
| `demo.yaml` | заглушка вместо сети: проверить всё, ничего не потратив |
| `default.yaml` | значения по умолчанию, выписанные явно — образец для своих |
| `books-json.yaml` | выходная политика: строгий JSON по схеме, два переспроса |
| `reviewer.yaml` | судья оценивает каждый ответ по трём признакам |
| `frugal.yaml` | входная политика и бюджет: короткие запросы, жёсткий потолок трат |
