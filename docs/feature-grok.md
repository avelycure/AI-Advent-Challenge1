# feature/grok — пятый провайдер, Grok от xAI

Ветка отведена от `main`, поэтому сравнение ниже — разница именно с ним.

## Коротко

В `main` провайдеров было четыре: DeepSeek, ChatGPT, YandexGPT и GigaChat.
В этой ветке добавлен пятый — Grok от xAI.

Отдельного клиента не потребовалось: xAI говорит на OpenAI-совместимом
протоколе по адресу `https://api.x.ai/v1`, авторизация обычным Bearer. Это
проверено живым запросом до написания кода, а не взято из документации.

## Что изменилось

| | Было (`main`) | Стало |
|---|---|---|
| Провайдеров в списке | четыре | пять |
| Ключ Grok | — | `XAI_API_KEY` или `~/.grok-key` |
| Неверный ключ с кодом 400 | показывался как «Провайдер отклонил запрос (400)» | «Ключ отклонён провайдером» |
| Отсутствие кредитов | нераспознанный отказ 403 | понятное сообщение с предложением выбрать другого провайдера |

## Две особенности xAI, которые пришлось учесть

**На неверный ключ отвечает кодом 400, а не 401.** У остальных четырёх
провайдеров неверный ключ — это 401, и разбор ошибок опирался на это. Grok
возвращает `400 invalid-argument` с текстом `Incorrect API key provided`,
и без отдельной ветки разбора пользователь увидел бы невнятное «Провайдер
отклонил запрос (400)».

**Бесплатного тарифа нет.** Аккаунт без купленных кредитов получает отказ
на любой запрос, включая список моделей:

```
403 permission-denied: Your newly created team doesn't have any credits
    or licenses yet.
```

Это тоже разобрано отдельно: сообщение прямо говорит, что дело в кредитах,
а не в ключе или сети, и предлагает выбрать другого провайдера.

## Откуда взялся список моделей

Не из документации и не по памяти. Эндпоинт `https://api.x.ai/v1/api-key`
работает даже без кредитов и возвращает права ключа — в них перечислены
модели, доступные конкретному аккаунту:

```
grok-4.6, grok-4.5, grok-4.3, grok-build-0.1,
grok-4.20-0309-reasoning, grok-4.20-0309-non-reasoning,
grok-4.20-multi-agent-0309
```

В программу вынесены три обычных чат-модели: `grok-4.3`, `grok-4.5` и `grok-4.6`.

Размеры контекстных окон поставлены заведомо осторожно — 131 072 токена.
Точные значения отдаёт эндпоинт `/v1/language-models`, но он требует кредитов,
поэтому проверить их сейчас нельзя. Когда доступ появится, значения стоит
уточнить оттуда.

## Что проверено и что нет

Проверено на живом API: адрес и протокол, авторизация, действительность ключа
через `/v1/api-key`, сообщение при отсутствии кредитов, сообщение при неверном
ключе. Интерфейс проверен регрессией — 60 проверок по пяти провайдерам.

Не проверено: успешный ответ модели. Для него нужны кредиты, а бесплатного
доступа у xAI нет. Тот же разрыв есть у DeepSeek с нулевым балансом
и у OpenAI, для которого ключа нет вовсе.
