# Как пользоваться агентом

Все команды в этом файле проверены запуском.

## Установка — один раз

```bash
cd ~/Personal/ai-advent-1
ln -s "$(pwd)/agent" ~/.local/bin/agent
```

Первый запуск сам создаст окружение и поставит зависимости. Если команда
не находится, добавьте в `~/.zshrc`: `export PATH="$HOME/.local/bin:$PATH"`.

## Три способа запустить

```bash
agent --demo                  # заглушка: всё работает, денег не тратит
agent                         # спросит провайдера, ключ и модель
agent --config default        # ChatGPT, ключ подхватит из ~/.openai-key
```

Ключи агент только читает — из переменной окружения провайдера или из файла
рядом (`~/.openai-key`, `~/.groq-key` и т. п.). Сам он их никуда не пишет.

**Бесплатно, но на живой модели:**

```bash
agent --provider groq --model qwen/qwen3.8-27b
```

У Groq и OpenRouter бесплатный тариф. Тариф ограничивает частоту: на частых
запросах приходит отказ, надо подождать.

## Что агент умеет

| Возможность | Как выглядит |
|---|---|
| Разговор с памятью | обычный диалог; модель видит всю переписку |
| Три явных слоя памяти | `/memory`: текущий диалог, данные задачи, профиль и проект |
| Четыре стратегии контекста | `/strategy`: вся история, скользящее окно, факты, пересказ |
| Картотека фактов | важные сведения ключ-значение: `/facts` |
| Ветки диалога | два продолжения от одного места: `/checkpoint`, `/branch`, `/switch` |
| Сжатие истории | начало разговора заменяется пересказом: `/summary`, `/compress` |
| Восемь провайдеров, 26 моделей | `/change_model` меняет модель, не теряя разговор |
| Своя сессия у каждого запуска | два терминала не пересекаются ничем |
| Возврат в прошлый разговор | `--continue`, `--resume`, `--sessions`; поиск по переписке |
| Один вопрос без диалога | `--ask "…"`, для скриптов `--json` |
| Настройка при запуске | любое поле конфига флагом или `--set` |
| Входная политика | длина запроса, запрещённые слова, шаблон-обёртка |
| Выходная политика | строгий JSON/YAML/таблица по схеме, переспрос при нарушении |
| Судья | оценка ответа отдельной моделью по признакам |
| Бюджет | потолок по деньгам, токенам и числу запросов |
| Под-агенты | вызов командой `/agent` или самой моделью |
| Сто агентов сразу | `./spawn.sh --agents 100` |

| `/tokens` | из чего сложится следующий запрос и как росла цена диалога |
| `/strategy` | как собирается запрос: `full`, `window`, `facts`, `summary` |
| `/facts` | картотека важных сведений; её можно поправить руками |
| `/memory` | показать short, working и long; явно записать или забыть значение |
| `/checkpoint` | запомнить место разговора, от которого отводят ветки |
| `/branch` | отвести ветку и продолжать разговор в ней |
| `/branches` | список веток и точек возврата |
| `/switch` | перейти в другую ветку |
| `/summary` | пересказ, которым заменено начало разговора |
| `/compress` | свернуть начало разговора в пересказ прямо сейчас |
| `/config` | конфиг агента целиком, ключ скрыт |
| `/agent` | список под-агентов; `/agent frugal Вопрос` — вызвать |
| `/rename` | переименовать сессию — по имени её видно в `--sessions` |
| `/change_model` | сменить модель или провайдера, сохранив разговор |
| `/change_llm_params` | температура, предел длины, стоп-строки |
| `/retry` | переспросить последний вопрос на текущей модели |
| `/new` | новая сессия; прежняя остаётся на диске |
| `/exit` | выход, он же Ctrl+D |

## Три слоя памяти

Обычный разговор попадает только в `short`. Фраза «запомни это» сама по себе
не превращает данные в более долгую память: слой выбирается командой явно.

| Слой | Для чего | Жизненный цикл |
|---|---|---|
| `short` | реплики текущего диалога | очищается `/new`, копируется при ветвлении |
| `working` | цель, ограничения и данные текущей задачи | сохраняется с сессией, очищается `/new`, ветвится вместе с задачей |
| `long` | профиль пользователя и устойчивые данные проекта | сохраняется между сессиями и переживает `/new` |

Показать всё содержимое и число реплик short-memory:

```text
Вы › /memory
```

Записать или заменить данные текущей задачи:

```text
Вы › /memory working цель=подготовить релиз
Вы › /memory working платформа=Android
```

В долговременной памяти четыре обязательных раздела:

```text
Вы › /memory long profile обращение=Иван
Вы › /memory long profile language=русский
Вы › /memory long rules no_push=без явной команды
Вы › /memory long decisions storage=PostgreSQL
Вы › /memory long knowledge deploy=GitHub Actions
```

`profile` действует во всех проектах. `rules`, `decisions` и `knowledge`
относятся только к проекту, из которого запущен агент. Пустое значение удаляет
ключ из названного слоя и раздела:

```text
Вы › /memory working платформа=
Вы › /memory long decisions storage=
```

`/memory short` только показывает панель: краткосрочная память заполняется
обычными репликами, прямой записи в неё нет. Короткий псевдоним команды — `/mem`.

В запрос слои идут в таком порядке: системный промпт → долговременный профиль →
долговременная память проекта → working → пересказ или факты выбранной стратегии →
дословная часть short → текущий вопрос. При включённой истории working и long
участвуют при любой стратегии; их размер отдельно виден в `/tokens`.
`--no-history` отключает историю, рабочую и проектную память для запросов этого
запуска. Профиль пользователя продолжает применяться к каждому вопросу.

### `/memory working` и `/facts` — не одно и то же

`/memory working` содержит только то, что человек сохранил явно, всегда
добавляется к запросу и живёт ровно вместе с текущей задачей.

`/facts` показывает другую, автоматическую картотеку. Её составляет модель из
реплик пользователя и собственных ответов; она добавляется к запросу только при
`--strategy facts`. Поэтому `/facts` удобно использовать как сжатое напоминание
о длинном разговоре, а working — как контролируемый список условий задачи.

### Хранение

- short и working: `~/.llm-agent/sessions/<id>.json` и снимки веток этой сессии;
- общий профиль: `~/.llm-agent/memory/profile.json`;
- правила, решения и знания: файл проекта в `~/.llm-agent/memory/projects/`.

Проект — ближайший родительский каталог с `.git`, а если его нет — текущий
каталог. Путь превращается в хеш имени файла, поэтому проектные правила не
протекают между репозиториями. Файлы памяти закрыты правами `0600`, каталоги —
`0700`. `--rm-session all` удаляет сессии, но не долговременную память;
`--no-save` отключает запись сессии, но явная команда `/memory long ...`
по-прежнему сохраняется.

Память хранит обычный текст и не предназначена для секретов. Имена вроде
`api_key`, `*_token`, `*_password` и `private_key` отвергаются; ключи провайдера
оставляйте в переменных окружения или специальных файлах ключей.

### Проверка `/new`

Состояние проверяется без сети:

```text
$ agent --demo
Вы › Кодовое слово апельсин
Вы › /memory working задача=подготовить релиз
Вы › /memory long profile обращение=Иван
Вы › /memory
# short содержит диалог, working содержит задачу, long содержит обращение

Вы › /new
Вы › /memory
# short: 0 сообщений, working: 0 записей, long: обращение=Иван
```

Если повторить опыт на живой модели, после `/new` она получает обращение из
профиля, но не получает ни «апельсин», ни задачу релиза.

## Настройка при запуске

Конфиг — основа, команда накрывает его сверху. Названное поле меняется,
остальные остаются.

```bash
agent --model gpt-5.4-nano --max-tokens 150      # подешевле и покороче
agent --format json --set attempts=3             # строго JSON, с переспросом
agent --max-cost 0.05                            # не тратить больше пяти центов
agent --no-history                               # каждый вопрос сам по себе
agent --set history.window=2000                  # тесное окно: увидеть переполнение
agent --set history.on_overflow=trim             # не падать, а забывать начало
agent --set history.on_overflow=send             # отправить как есть: слово провайдеру
agent --strategy window --keep-last 4            # в модель уходит только хвост
agent --strategy facts                           # картотека важных сведений
agent --no-compress                              # то же, что --strategy full
agent --keep-last 4 --compress-every 6           # короче хвост, чаще пересказ
agent --set 'template=Переведи на английский: {input}'
agent --config '{"model": "gpt-5.4-nano"}'       # конфиг строкой, без файла
```

Короткий флаг есть у десяти частых полей: `--model`, `--provider`,
`--temperature`, `--max-tokens`, `--system-prompt`, `--append-system-prompt`,
`--format`, `--max-cost`, `--no-history`, `--strategy`, `--no-compress`,
`--keep-last`, `--compress-every`, `--agent-name`. Всё остальное — через
`--set поле=значение`, сколько нужно раз.

**Порядок:** конфиг → флаг → `--set`. Проверить результат:

```bash
agent --config frugal --temperature 0.2 --show-config
```

Печатает собранный конфиг и выходит. Жёлтым — что отличается от умолчаний.
Ничего не отправляет и денег не стоит.

## Сессии

Каждый запуск — своя сессия со своей short- и working-memory. Разговор и данные
текущей задачи сохраняются после каждого ответа или команды `/memory working`,
поэтому в них можно вернуться после перезапуска. Long-memory загружается
отдельно и доступна новой сессии сразу.

```bash
agent --name "Алгоритмы графов"   # назвать сессию сразу
agent --sessions                  # список: имя, когда, обменов, первый вопрос
agent --sessions Дейкстры         # только те, где встречается слово
agent --continue                  # в самый свежий разговор
agent --resume 1                  # по номеру из списка
agent --resume "Алгоритмы графов" # по имени
agent --resume 06a74fd1           # по идентификатору или его началу
agent --resume                    # без имени — предложит выбрать
agent --rm-session "Алгоритмы"    # удалить; all — удалить все
agent --no-save                   # не сохранять эту сессию
```

Список выглядит так:

```
 №   Имя                  Когда         Обменов   О чём говорили
 1   Алгоритмы графов     только что          2   Привет! Меня зовут Влад, я изучаю…
 2   Подбор книг          2 ч назад           5   Посоветуй книги по алгоритмам
```

**Имя придумывается само**, если вы его не задали: берётся тема, которую
сочинила модель, а пока её нет — начало первого вопроса. Переименовать можно
в любой момент:

```
Вы › /rename Разбор алгоритмов
```

Вернувшись в сессию, настройки можно поменять: `--resume 1 --model gpt-5.4`
продолжит тот же разговор на другой модели.

Переписка и working-memory лежат файлами в `~/.llm-agent/sessions/`, читать их
может только владелец, и лежат они до тех пор, пока вы их не удалите.
Long-memory хранится отдельно в `~/.llm-agent/memory/`. **Ключ провайдера в
файлы не попадает.**

Одиночные запросы через `--ask` не сохраняются, но читать сохранённое умеют:

```bash
agent --continue --ask "Как меня зовут?"
```

Если одну сессию открыть в двух окнах, ничего не потеряется: разговор второго
окна продолжится отдельной сессией, и об этом будет сказано прямо.

## Под-агенты

Под-агент — отдельный процесс со своим конфигом и своей памятью. Родителю
возвращается только его ответ.

**Зовёте вы.** Первое слово — **имя конфига**, дальше вопрос:

```
Вы › /agent books-json Книги Нассима Талеба
Вы › /agent frugal temperature=0.1 -- Что такое хороший код
```

До `--` правки конфига, после — вопрос. Список конфигов покажет `/agent` без
аргументов.

Частая ошибка — написать сразу вопрос: `/agent Какие книги написал Талеб`.
Первое слово тогда принимается за имя конфига. Агент об этом скажет и напомнит
нужный порядок.

**Зовёт модель сама:**

```bash
agent --config orchestrator
```

```
Вы › Дай ровно пять книг Нассима Талеба строгим JSON по схеме

╭─ 🔧 Модель сама вызвала под-агента books-json ───────────────╮
│ Сессия  91d00506 · своя память, отдельный процесс           │
│ Расход  2.1 с · 497 ток. · $0.000905                        │
╰─────────────────────────────────────────────────────────────╯
```

Включается полем конфига:

```bash
agent --set 'tools.enabled=[spawn_agent]' --set tools.max_calls=2
```

Инструменты умеют не все модели. Из бесплатных умеют `qwen/qwen3.8-27b` и
`openai/gpt-oss-120b` на Groq; `groq/compound` — нет, и агент скажет об этом
прямо.

Расход под-агента идёт в общий счёт отдельной строкой — и когда зовёте вы, и
когда модель:

```
Запросов к API   3
Из них           основной — 1 запрос · инструмент — 1 запрос · под-агент — 1 запрос
```

## Как проверить, что всё работает

### Быстро и бесплатно

```bash
./test.sh          # полный набор тестов на локальных заглушках
./livecheck.py     # 23 сценария настоящих запусков, ~20 с
```

`./test.sh` проверяет части, `./livecheck.py` — то, что делаете вы: запускает
команду с разными параметрами, разговаривает, зовёт под-агента, возвращается в
сессию. Каждый сценарий подписан требованием, которое подтверждает.

### На живой модели

```bash
./livecheck.py --live                     # Groq, бесплатный тариф
./livecheck.py --live --provider openai   # платно, спросит подтверждение
```

Полный прогон по OpenAI обходится примерно в полтора-два цента и показывает
трату в конце.

### Проверка ментора: сто агентов

```bash
./spawn.sh --agents 100
```

```
Создано и опрошено         100 агентов
Ответили                   100
Соединений открыто         8 на 100 агентов
Времени с начала до конца  0.07 с
```

Сто агентов, 26 моделей восьми провайдеров, у каждого свой промпт, своя
температура и свой набор политик. Ни одного вопроса человеку.

### Прочие опыты

```bash
./compare.sh       # пять рычагов управления ответом, по одному
./reasoning.sh     # четыре способа поставить одну задачу
./tokens.sh        # короткий, длинный и переполненный диалог — рядом
./compress.sh      # вся история, обрезка и сжатие — на одном разговоре
./context.sh       # четыре стратегии и ветвление — на одном сборе ТЗ
```

`./tokens.sh` без флагов идёт на заглушке и денег не стоит. С `--live` уходит
в настоящую модель, а `--window 2000` задаёт, в какое окно загонять диалог.

`./compress.sh` ведёт один разговор тремя способами и показывает итоги рядом:
сколько вопросов прошло, во что обошлось и — на `--live` — помнит ли агент имя,
названное в самом начале.

`./context.sh` собирает одно и то же ТЗ четырьмя стратегиями и показывает
рядом расход, число служебных запросов и то, что каждая стратегия запомнила.
В конце — ветвление: две ветки от одной точки и один и тот же вопрос в каждой.

## Если что-то не так

| Что видите | Что делать |
|---|---|
| `command not found: agent` | `~/.local/bin` не в PATH — добавьте в `~/.zshrc` |
| `не найден API-ключ для …` | положите ключ в файл рядом или задайте переменную окружения |
| `нет поля «…». Доступны: …` | опечатка в `--set`; правильные имена покажет `--show-config` |
| `нет конфига «…»` | опечатка или сразу вопрос вместо имени; нужно `/agent <конфиг> <вопрос>` |
| `Эта модель не умеет вызывать инструменты` | смените модель или `--set tools.enabled=[]` |
| `Слишком много запросов (429)` | бесплатный тариф ограничивает частоту, подождите |
| набранное пропадает или слова попадают не в ту строку | было до правки от 9 сентября; обновите ветку |
| `денежный лимит будет превышен` | поднимите `--max-cost` или уберите его |
| `диалог не помещается в окно модели` | `/new`, вопрос покороче или `--set history.on_overflow=trim` |
| `Ответ обрезан: упёрся в max_tokens` | это не переполнение контекста — поднимите `max_tokens` |

Полный список флагов — `agent --help`. Устройство изнутри — `ARCHITECTURE.md`.
