# Описания веток

Одна ветка — один файл. Каждый этап работы делается в отдельной ветке,
отведённой от `main`, и сопровождается файлом с описанием: чем текущая
реализация отличается от предыдущей.

Файл называется по имени ветки: ветка `feature/grok` → `docs/feature-grok.md`.

Смысл файла — не пересказ коммитов. Список изменённых строк и так виден
в `git diff`. Здесь пишется то, чего в diff нет: что поменялось в поведении
программы, почему выбрано именно такое решение и что выяснилось по дороге.

| Ветка | Описание |
|---|---|
| `main` | базовая реализация: чат с LLM, история диалога, счётчики токенов, подстановка реквизитов |
| `feature/response-control` | управление форматом, длиной и завершением ответа (описание — в своей ветке) |
| `feature/llm-params` | переключение параметров генерации во время диалога (описание — в своей ветке) |
| [`feature/grok`](feature-grok.md) | пятый провайдер: Grok от xAI |
